# Fit33 v8.1.0 — Biblioteca, Perfil y Automatización

## Incluye

- Biblioteca ampliada de ejercicios por grupo muscular con búsqueda y filtros.
- Acceso a la biblioteca desde Entrenamientos.
- Editar perfil funcional y persistente usando user_preferences existente.
- Validación de objetivos y preferencias antes de guardar.
- El perfil principal muestra los valores editables reales de la cuenta.
- El Coach Adaptativo puede aplicar y guardar una reorganización o reducción semanal en workout_plans tras confirmación.
- El plan semanal se persiste para que las decisiones aceptadas no queden solo en una vista previa.
- Tests existentes de v8 se conservan.
